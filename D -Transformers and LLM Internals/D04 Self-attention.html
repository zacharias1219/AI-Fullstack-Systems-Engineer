Self-attention

How does a token at position i inspect earlier tokens in the sequence and pull their relevant features into its own residual stream? This page covers single-head scaled dot-product self-attention: Q, K, and V linear projections, the 1 / sqrt(d_k) variance stabilizer, upper-triangular causal masking, row-wise softmax routing, and the O(T^2) compute and memory wall. Multi-head variants (MHA, GQA, MQA, MLA) are D05, positional encodings are D06, and FlashAttention kernels are K12.

Two unit-variance Gaussian vectors q and k each have dimension d_k = 64. Before dividing by sqrt(64) = 8, what is the theoretical standard deviation of their raw dot product q . k: 1.0, 8.0, or 64.0?
8.0 (7.77 in the kata sample). Each of the 64 coordinate products q_m * k_m has mean 0 and variance 1, so the sum of 64 independent terms has variance d_k = 64 and standard deviation sqrt(64) = 8.0. Without dividing by sqrt(d_k), feeding logits of magnitude +/-8 to +/-16 into softmax collapses the row into a near one-hot vector (entropy drops from 3.40 bits to 0.60 bits in the kata) and starves Q and K of gradients.
To prevent token i from attending to future tokens j > i in causal self-attention, a teammate sets masked positions in the score matrix to 0.0 instead of -infinity before calling softmax. Does that block future information?
No. Because exp(0.0) = 1.0, every masked future position gets a positive numerator of 1.0 inside softmax. In the kata on a 6-token sequence, masking with 0.0 instead of -1e9 leaks an average of 0.317 probability mass per row onto future tokens, and perturbing token t = 5 ("bleeding") corrupts earlier token outputs out[0..4] by 1.0316 instead of 0.00e+00.
In a 6-token causal self-attention layer on ["Patient", "took", "warfarin", "and", "developed", "bleeding"], what is the attention weight A[0, 0] and the Shannon entropy of row t = 0 ("Patient"), regardless of the learned matrices W_Q and W_K?
A[0, 0] is always 1.000 and its entropy is always 0.00 bits. At position i = 0, all columns j > 0 are masked to -infinity (exp(-inf) = 0), leaving column j = 0 as the only valid destination. Because softmax normalizes each row to sum to 1.0, token 0 must place 100% of its weight on itself.

The core idea

From D03, the input embedding table W_E assigns one static vector to each token ID: "bleeding" starts with the exact same vector whether the sentence mentions "warfarin" or "paint". Self-attention is the data-dependent routing step that turns static vectors into contextual representations. Given a sequence of residual stream states X in R^(T x d_model), each token projects its state into three distinct roles: a query q_i (what I am looking for), a key k_j (what content I advertise to others), and a value v_j (the payload I hand over if selected).

Routing happens in five matrix operations. First, X multiplies by W_Q, W_K, and W_V to produce Q, K, and V in R^(T x d_k). Second, all pairwise dot products Q @ K^T measure how strongly every query i matches every key j. Third, dividing by sqrt(d_k) keeps the score variance at 1.0 so softmax does not saturate. Fourth, in an autoregressive decoder, an upper-triangular causal mask overwrites future entries (j > i) with -infinity so token i cannot peek ahead, and row-wise softmax converts each row into a probability distribution A_i that sums to 1.0. Finally, multiplying A @ V blends the permitted value vectors into a new contextualized vector for every position.

Memory hook

Remember P-D-S-M-S-V (Project, Dot, Scale, Mask, Softmax, Value-sum): Project X into Q, K, V (T, d_k); Dot Q @ K^T into (T, T) scores; Scale by 1 / sqrt(d_k) to fix variance at 1; Mask j > i to -infinity; Softmax row-wise so weights sum to 1; Value-sum A @ V back to (T, d_k).

How it works

Queries, keys, and values: why three separate projections?

If you computed raw self-similarity X @ X^T directly on residual vectors, the score matrix would be symmetric (score(i, j) == score(j, i)) and every token would have to pass its entire residual state unchanged whenever selected. Language routing is asymmetric: in "Patient took warfarin and developed bleeding", the token bleeding (t = 5) needs to search backward for an anticoagulant cause (warfarin, t = 2), which is different from what warfarin searches for at t = 2. Separate learned matrices W_Q, W_K in R^(d_model x d_k) and W_V in R^(d_model x d_v) break that symmetry. Q_i = x_i W_Q encodes the search query, K_j = x_j W_K encodes the addressable key, and V_j = x_j W_V extracts only the subspace of features that token j should write into downstream tokens.

Q = X @ W_Q    # (T, d_model) @ (d_model, d_k) -> (T, d_k)
K = X @ W_K    # (T, d_model) @ (d_model, d_k) -> (T, d_k)
V = X @ W_V    # (T, d_model) @ (d_model, d_v) -> (T, d_v)  (usually d_v = d_k)

Why scale by 1 / sqrt(d_k)? Variance derivation and softmax Jacobian

Assume the components of query vector q and key vector k are independent random variables with mean 0 and variance 1. Their dot product is the sum of d_k product terms: s = sum_{m=1..d_k} q_m k_m. Because E[q_m k_m] = E[q_m] E[k_m] = 0 and Var(q_m k_m) = E[q_m^2] E[k_m^2] = 1 * 1 = 1, the variance of the sum grows linearly with head dimension: Var(q . k) = d_k, and its standard deviation is sqrt(d_k). At d_k = 64, unscaled scores have std 8.0 (7.77 in the kata); at d_k = 256, std reaches 16.0 (15.53 in the kata).

When large score differences hit softmax p_j = exp(s_j) / sum_r exp(s_r), the largest logit dominates exponentially, pushing p_max close to 1.0 and all other weights toward 0.0. In the backward pass, the Jacobian of softmax with respect to score s_j is d(p_m)/d(s_j) = p_m (1_{m=j} - p_j). Every entry of that Jacobian is proportional to p_m (1 - p_m) or -p_m p_j. When p_max approaches 1.0, p_max (1 - p_max) vanishes toward 0, freezing gradient flow into W_Q and W_K. Dividing by sqrt(d_k) rescales score variance to Var(s / sqrt(d_k)) = d_k / d_k = 1.0 across all head widths.

Var(q . k) = sum_{m=1..d_k} Var(q_m * k_m) = d_k * 1 = d_k   =>  std(q . k) = sqrt(d_k)
Var((q . k) / sqrt(d_k)) = d_k / (sqrt(d_k))^2 = 1.0          =>  std = 1.0
Softmax Jacobian diagonal: dp_j / ds_j = p_j * (1 - p_j) -> 0 as p_max -> 1
Check: at d_k = 64 in the kata, how much do the average max weight p_max, Shannon entropy, and gradient factor p_max(1 - p_max) change when you drop the 1 / sqrt(64) scaling factor?
With 1 / sqrt(64) scaling, score std is 0.97, average p_max is 0.250, entropy is 3.40 bits, and the gradient factor is 0.1786. Without scaling, score std jumps 8x to 7.77, p_max spikes to 0.853 (0.998 on the 6-token seed), entropy collapses from 3.40 bits to 0.60 bits, and the gradient factor drops to 0.1055 (and down to 0.0891 at d_k = 256).

Causal masking: why -infinity before softmax and never 0

An autoregressive language model predicts token i + 1 from tokens 0..i during a single parallel training forward pass (D01). For query i to remain causally isolated from future tokens j > i, the attention weight A[i, j] must equal exactly zero. Because softmax applies an exponential exp(s_{i,j}) to every entry, setting a masked entry to 0.0 produces exp(0.0) = 1.0, which gives future tokens a positive share of the row sum. Instead, we add a causal mask matrix M where M[i, j] = 0 for j <= i and M[i, j] = -infinity (in floating-point code, -1e9 or torch.finfo(dtype).min) for j > i. Then exp(-infinity) = 0.0, and the row-wise denominator sums only over valid past and present keys j <= i.

Never apply the causal mask after softmax by zeroing out the upper triangle of A: if you compute softmax over all T columns and then zero out j > i, the remaining weights in row i no longer sum to 1.0 (they sum to 1 - sum_{j>i} A[i, j]), and the denominator itself still depends on the future logits s_{i, j>i}, leaking future gradient and magnitude signal into the prefix.

Value routing and quadratic O(T^2) complexity

Once the causal weight matrix A in R^(T x T) is normalized, the output is Out = A @ V in R^(T x d_v). Row i of Out is the convex combination sum_{j=0..i} A[i, j] v_j. Count the arithmetic cost for one head: computing Q, K, and V takes 3 * (2 * T * d_model * d_k) FLOPs, which scales linearly with T. Computing Q @ K^T multiplies (T, d_k) by (d_k, T) in 2 * T^2 * d_k FLOPs, and computing A @ V multiplies (T, T) by (T, d_k) in another 2 * T^2 * d_k FLOPs, totaling 4 * T^2 * d_k attention matrix FLOPs plus O(T^2) HBM reads and writes to materialize S and A. At short T = 512, linear projections dominate; past T = 4,096 to 32,768, the quadratic T^2 term becomes the primary compute and memory bandwidth bottleneck.

Check: if sequence length T quadruples from 2,048 to 8,192 while d_model and d_k stay fixed, by what factor do the projection FLOPs (X @ W_QKV) and the attention score/value FLOPs (Q @ K^T and A @ V) grow?
Projection FLOPs scale linearly with T and grow by 4x. Attention matrix FLOPs (4 * T^2 * d_k) and the intermediate T by T attention matrix memory scale quadratically with T^2 and grow by 4^2 = 16x.

Kata: single-head causal self-attention from scratch

A self-contained 83-line Python script implementing single-head causal self-attention on a 6-token clinical sentence (d_model = 64, d_k = 64), verifying exact tensor shapes and row sums, testing future-token leakage when token t = 5 is perturbed under three masking regimes, and measuring softmax saturation across head widths d_k in {16, 64, 256}.

"""D04 Self-attention kata: Q/K/V projections, 1/sqrt(d_k) scaling, causal mask, softmax saturation."""
import math, random

random.seed(42)
TOKENS = ["Patient", "took", "warfarin", "and", "developed", "bleeding"]
T, D_MODEL, D_K = len(TOKENS), 64, 64

def rand_mat(r, c, scale=1.0):
    return [[random.gauss(0.0, scale) for _ in range(c)] for _ in range(r)]

def matmul(A, B):
    return [[sum(a * b for a, b in zip(row, col)) for col in zip(*B)] for row in A]

def transpose(M):
    return [list(col) for col in zip(*M)]

def softmax_stats(scores):
    A, ents, pmaxs, grads = [], [], [], []
    for row in scores:
        m = max(row)
        ex = [math.exp(x - m) for x in row]
        s = sum(ex)
        p = [e / s for e in ex]
        ent = abs(-sum(pi * math.log2(max(pi, 1e-12)) for pi in p))
        pm = max(p)
        A.append(p); ents.append(ent); pmaxs.append(pm); grads.append(pm * (1.0 - pm))
    return A, ents, pmaxs, grads

X = rand_mat(T, D_MODEL, 1.0)
s_init = 1.0 / math.sqrt(D_MODEL)
W_Q, W_K, W_V = rand_mat(D_MODEL, D_K, s_init), rand_mat(D_MODEL, D_K, s_init), rand_mat(D_MODEL, D_K, s_init)

def self_attention(X_in, scale=True, causal=True, mask_val=-1e9):
    Q, K, V = matmul(X_in, W_Q), matmul(X_in, W_K), matmul(X_in, W_V)
    raw = matmul(Q, transpose(K))
    div = math.sqrt(D_K) if scale else 1.0
    scores = [[(mask_val if (causal and j > i) else raw[i][j] / div) for j in range(T)] for i in range(T)]
    A, ents, pmaxs, grads = softmax_stats(scores)
    out = matmul(A, V)
    return out, A, raw, ents, pmaxs, grads

out_c, A_c, raw_s, ent_c, pmax_c, gf_c = self_attention(X, scale=True, causal=True)
print("=== 1. Tensor shapes & causal row sums (T=6, d_model=64, d_k=64) ===")
print(f"X: ({len(X)}, {len(X[0])}) -> Q,K,V: ({T}, {D_K}) -> Scores: ({T}, {T}) -> A: ({T}, {T}) -> Out: ({len(out_c)}, {len(out_c[0])})")
print("Row sums of A:", [round(sum(r), 6) for r in A_c])
upper_sum = sum(A_c[i][j] for i in range(T) for j in range(i + 1, T))
print(f"Upper-triangle future weights sum: {upper_sum:.2e}")
print("\nCausal attention weights A (rows=query i, cols=key j):")
for i, tok in enumerate(TOKENS):
    r_str = " ".join(f"{A_c[i][j]:.3f}" for j in range(T))
    print(f"  t={i} ({tok:9s}): [{r_str}]  entropy={ent_c[i]:.2f} bits")

# 2. Future-token invariance test (perturb final token t=5 'bleeding')
X_pert = [row[:] for row in X]
X_pert[5] = [x + random.gauss(0.0, 3.0) for x in X_pert[5]]
out_c_p, *_ = self_attention(X_pert, scale=True, causal=True)
out_b, *_ = self_attention(X, scale=True, causal=False)
out_b_p, *_ = self_attention(X_pert, scale=True, causal=False)
out_z, A_z, *_ = self_attention(X, scale=True, causal=True, mask_val=0.0)
out_z_p, *_ = self_attention(X_pert, scale=True, causal=True, mask_val=0.0)

def max_diff_prefix(M1, M2, rows=5):
    return max(abs(M1[i][d] - M2[i][d]) for i in range(rows) for d in range(D_K))

z_future = sum(A_z[i][j] for i in range(T) for j in range(i + 1, T)) / T
print("\n=== 2. Future-token leakage test (perturbing t=5 'bleeding') ===")
print(f"Causal mask (-1e9) max |diff| on out[0..4]:      {max_diff_prefix(out_c, out_c_p):.2e}")
print(f"No mask (bidirectional) max |diff| on out[0..4]: {max_diff_prefix(out_b, out_b_p):.4f}")
print(f"Buggy mask (0.0 instead of -inf) future weight:  {z_future:.3f} avg/row, diff={max_diff_prefix(out_z, out_z_p):.4f}")

# 3. Scaling test across head dimensions d_k (16 queries x 16 keys)
print("\n=== 3. Scaled (1/sqrt(d_k)) vs Unscaled softmax saturation ===")
N_BENCH = 16
for d_test in (16, 64, 256):
    random.seed(12)
    Qt, Kt = rand_mat(N_BENCH, d_test, 1.0), rand_mat(N_BENCH, d_test, 1.0)
    s_un = matmul(Qt, transpose(Kt))
    s_sc = [[v / math.sqrt(d_test) for v in r] for r in s_un]
    flat_un = [v for r in s_un for v in r]
    mean_un = sum(flat_un) / len(flat_un)
    std_un = math.sqrt(sum((v - mean_un) ** 2 for v in flat_un) / len(flat_un))
    std_sc = std_un / math.sqrt(d_test)
    _, ent_sc, pm_sc, gf_sc = softmax_stats(s_sc)
    _, ent_un, pm_un, gf_un = softmax_stats(s_un)
    avg = lambda xs: sum(xs) / len(xs)
    print(f"d_k={d_test:3d} | score_std: unscaled={std_un:5.2f}, scaled={std_sc:4.2f} | "
          f"scaled: p_max={avg(pm_sc):.3f}, ent={avg(ent_sc):.2f}b, grad_f={avg(gf_sc):.4f} | "
          f"unscaled: p_max={avg(pm_un):.3f}, ent={avg(ent_un):.2f}b, grad_f={avg(gf_un):.4f}")

What to notice

  1. Exact causal isolation: in Section 1, the upper triangle of A sums to 0.00e+00 and every row sums to 1.0. When token t = 5 ("bleeding") is heavily perturbed in Section 2, outputs out[0..4] change by 0.00e+00.
  2. Row 0 is always deterministic: at t = 0 ("Patient"), only column 0 is unmasked, so A[0] = [1.000, 0.000, ...] with 0.00 bits of entropy. Routing diversity only becomes possible as valid history grows with i.
  3. The 0.0 mask bug leaks 31.7% of attention mass: replacing -1e9 with 0.0 on future entries leaves exp(0) = 1 in the numerator, giving future tokens 0.317 average weight per row and causing a 1.0316 prefix output corruption when t = 5 changes.
  4. Variance scaling law holds empirically: across d_k = 16, 64, 256, unscaled score standard deviation grows as sqrt(d_k) (3.97, 7.77, 15.53 vs theoretical 4.0, 8.0, 16.0), whereas dividing by sqrt(d_k) locks score std near 1.0 (0.99, 0.97, 0.97) and keeps entropy near 3.40 bits.
Break it
  1. Off-by-one causal mask (j > i + 1). Change j > i to j > i + 1 in self_attention. Predict first: which future token can query i now read, and what happens to the prefix drift test when t = 5 is perturbed?
  2. Post-softmax masking bug. Set causal=False inside scores, then zero out A[i][j] = 0.0 for j > i after softmax_stats(scores) without renormalizing. Predict whether the row sums of A still equal 1.0 and whether perturbing t = 5 still alters out[0..4]!
  3. All-masked NaN row (padding + causal mask). Mask out column j = 0 as well for row i = 0 using float("-inf") (simulating a left-padded empty row). Predict what max(row) and x - m evaluate to in IEEE 754 floating point.

Scenario: a teammate ports your clinical note summarizer to a custom PyTorch attention wrapper to log attention maps. After 300 fine-tuning steps, teacher-forced evaluation perplexity drops from 8.4 to 1.04, yet live generation on a prompt repeats the last prompt word endlessly. How do you diagnose and fix it in five minutes?
  1. Recognize the signature immediately: teacher-forced perplexity of 1.04 is impossibly good for clinical text and indicates future-token leakage across the causal mask.
  2. Run the kata's future-perturbation test on one batch: randomize input token X[:, -1, :] and check (out_clean[:, :-1] - out_perturbed[:, :-1]).abs().max(). A non-zero diff confirms causal leakage.
  3. Inspect the custom wrapper's mask logic: PyTorch's nn.MultiheadAttention expects attn_mask where True means block (fill with -inf), whereas F.scaled_dot_product_attention with a boolean attn_mask treats True as keep (participate in attention). Passing a triu(k=1) boolean mask directly to SDPA keeps only future tokens and blocks past tokens!
  4. Replace the custom boolean mask with is_causal=True (or pass an explicit additive float mask with 0.0 on j <= i and -torch.inf on j > i).
  5. Re-run the future-perturbation test to verify 0.00e+00 prefix diff before restarting fine-tuning.

2 Mechanism 45 sGiven input X of shape T by d_model, we project it through three learned matrices W_Q, W_K, and W_V into queries, keys, and values of shape T by d_k. We compute all pairwise dot products Q times K transpose, which produces a T by T score matrix. Because two unit-variance vectors of length d_k have a dot-product variance of d_k, we divide by the square root of d_k to keep score variance at 1. In an autoregressive decoder, we add an upper-triangular causal mask that sets future columns j greater than i to negative infinity, apply row-wise softmax so each row sums to 1, and multiply by V.
3 Internals and limits 25 sWithout 1 over root d_k scaling at d_k equals 64, score standard deviation jumps to 8, collapsing softmax entropy from 3.40 bits to 0.60 bits in our run and killing gradients via the p times 1 minus p Jacobian factor. Computing Q K transpose and A V costs 4 T squared d_k FLOPs and O of T squared memory, making long-context prefill quadratic unless tiled with FlashAttention.

Say it like an engineer

Question: why does scaled dot-product attention divide by sqrt(d_k), and what breaks if you remove it?

"We divide by the square root of d_k to normalize the dot product scores so they don't get too big when the dimension is large, which helps the model train better and more stably."

"If query q and key k have independent unit-variance coordinates, their dot product is a sum of d_k terms each with variance 1, so the dot product has variance d_k and standard deviation sqrt(d_k). At d_k = 64, unscaled scores have std 8 instead of 1. When those large logits hit softmax, the exponential pushes the maximum probability p_max near 1 and all others near 0; in my benchmark at d_k = 64, dropping 1 / sqrt(64) collapsed average row entropy from 3.40 bits to 0.60 bits. Because every entry of the softmax Jacobian scales with p_i * (1 - p_i), saturation drives gradients to W_Q and W_K toward zero. Dividing by sqrt(d_k) restores unit variance regardless of head width."

The strong answer gives the probability derivation (sum of d_k unit variances), the backward-pass mechanism (softmax Jacobian p_i(1 - p_i)), and illustrative numbers from the kata (std 8, entropy 3.40 to 0.60 bits).

Traps

Each one sounds right. Say what is wrong with it before you open it.

"To mask out future tokens in causal attention, set the upper triangle of the score matrix Q @ K^T to zero before calling softmax."
Setting a logit to 0.0 before softmax evaluates to exp(0.0) = 1.0, which gives future tokens positive probability weight (leaking 31.7% average future weight per row in the kata). Masked positions must be set to -infinity (so exp(-inf) = 0.0) before softmax.
"You can apply the causal mask after softmax by multiplying the attention weight matrix A by a lower-triangular ones matrix."
Zeroing out j > i after softmax breaks row normalization so the remaining weights in row i sum to less than 1.0, and the softmax denominator sum_k exp(s_{i,k}) still includes future logits k > i, leaking future information into the scaling of every past weight.
"Self-attention has O(T^2) parameters because the attention matrix A is T by T."
The parameter count of single-head self-attention is independent of sequence length T: W_Q, W_K, W_V have 3 * d_model * d_k parameters (plus d_k * d_model for W_O). The T x T matrix A is a runtime activation computed on the fly, so compute and activation memory are O(T^2) while weights are O(d_model * d_k).
"Dividing by sqrt(d_k) is just an inference hyperparameter like sampling temperature and does not affect gradient flow."
While dividing by sqrt(d_k) acts like an attention softmax temperature of tau = sqrt(d_k), its critical purpose is during backpropagation: without it, unscaled logits of std sqrt(d_k) saturate softmax into a one-hot step function where the Jacobian p_i(1 - p_i) vanishes, preventing W_Q and W_K from learning.

Explain single-head causal self-attention in 90 seconds.
Follow the three levels above: outcome (routing past token features into current residual states), mechanism (X to Q, K, V in R^(T x d_k), S = Q K^T / sqrt(d_k), upper-triangular -inf causal mask, row-wise softmax A, weighted value sum A V), and internals (variance d_k derivation, softmax Jacobian vanishing without scaling, and 4 T^2 d_k quadratic compute).
Follow-upWhat are the exact shapes of every tensor from X to Out when batch size is B, sequence length is T, model width is d_model, and head dimension is d_k? X is (B, T, d_model); Q, K, V are (B, T, d_k); Q @ K^T and A are (B, T, T); Out = A @ V is (B, T, d_k).
Derive why the dot product of two independent d_k-dimensional vectors with zero mean and unit variance has standard deviation sqrt(d_k).
Let q_m and k_m have mean 0 and variance 1. By independence, E[q_m k_m] = 0 and Var(q_m k_m) = E[q_m^2] E[k_m^2] = 1. The dot product sum_{m=1..d_k} q_m k_m adds d_k independent terms, so its variance is d_k * 1 = d_k and its standard deviation is sqrt(d_k).
Follow-upWhat if q and k have coordinate variance sigma^2 instead of 1? Each product term has variance sigma^4, so the dot product has variance d_k * sigma^4 and standard deviation sigma^2 * sqrt(d_k).
Write the diagonal and off-diagonal terms of the softmax Jacobian dp_m / ds_j and explain why large logits cause vanishing gradients.
For p = softmax(s), dp_j / ds_j = p_j (1 - p_j) on the diagonal and dp_m / ds_j = -p_m p_j off the diagonal. When one logit is much larger than the rest, p_max approaches 1 and all other p_m approach 0, so every product p_j(1 - p_j) and -p_m p_j approaches 0.
Why does self-attention project X into separate Q and K matrices instead of computing softmax(X @ X^T / sqrt(d))?
X @ X^T is symmetric (entry (i, j) equals entry (j, i)) and forces every token to score highest with itself along the diagonal. Separate W_Q and W_K matrices allow asymmetric directed relationships, such as token 5 ("bleeding") attending strongly (0.623) to token 2 ("warfarin") without requiring token 2 to attend equally to token 5.
Follow-upWhy do we also need a separate value projection W_V instead of averaging the keys K or raw inputs X? Keys K live in the low-dimensional matching subspace tuned for dot-product scoring; W_V lets the head extract a completely different payload of features to add back into the residual stream.
How do you write a 5-line unit test in PyTorch or NumPy to prove a causal self-attention layer has zero future leakage?
Run a forward pass on random input X to get out1. Clone X into X2, add large noise to the last token X2[:, -1, :] += 10.0, and run a second forward pass to get out2. Assert that max(|out1[:, :-1] - out2[:, :-1]|) == 0.0 (within floating-point epsilon).
Compare the FLOPs of the QKV projections against the Q @ K^T and A @ V attention multiplies for one head, and find the crossover sequence length T where attention matrix FLOPs exceed projection FLOPs.
Projections cost 6 * T * d_model * d_k FLOPs; attention matrix multiplies cost 4 * T^2 * d_k FLOPs. Setting 4 * T^2 * d_k > 6 * T * d_model * d_k gives the crossover at T > 1.5 * d_model (for example, at d_model = 4,096, attention matrix FLOPs exceed QKV projection FLOPs once T > 6,144).
Follow-upIf you also count the output projection W_O (another 2 * T * d_k * d_model FLOPs), where is the crossover? Total projections become 8 * T * d_model * d_k, so the crossover is at T = 2 * d_model (T = 8,192 when d_model = 4,096).
Without any positional encoding (D06), what happens to the outputs of unmasked self-attention if you permute the input token rows of X?
Unmasked self-attention is permutation-equivariant: permuting the input rows of X by a permutation matrix P permutes the output rows by the exact same P (Attn(P X) = P Attn(X)), because dot products and weighted sums treat keys and values as an unordered set.
Why does passing -1e9 as the mask value throw an overflow error or corrupt tensors when running in native FP16 (float16), while BF16 handles it without issue?
IEEE 754 FP16 has only 5 exponent bits and a maximum finite magnitude of 65,504, so -1e9 overflows its finite range. BF16 has 8 exponent bits (matching FP32's dynamic range up to ~3.4e38). In portable code, use -float("inf") or torch.finfo(dtype).min.
In the kata, why does row t = 0 have 0.00 bits of attention entropy while row t = 4 has 2.27 bits?
Row t = 0 has only 1 unmasked key (column 0), so its distribution is [1.0] with maximum possible entropy log2(1) = 0.00 bits. Row t = 4 has 5 unmasked keys (columns 0..4), with maximum possible entropy log2(5) = 2.32 bits, and its weights spread nearly evenly across all 5 tokens (2.27 bits).
Follow-upWhat is the theoretical maximum Shannon entropy in bits for causal attention row i (0-indexed)? Because row i has i + 1 unmasked columns (0 through i), its maximum entropy is log2(i + 1) bits, achieved when all i + 1 weights equal 1 / (i + 1).

Mixed review

Three questions from earlier topics. Nobody tells you the topic in an interview.

D03: why does input embedding lookup W_E[i] execute in 0 arithmetic FLOPs while the output unembedding h @ W_U costs 2dV FLOPs per token?
At the input, token ID i is known, so hardware performs an O(d) contiguous memory gather of row i from W_E instead of multiplying a one-hot vector. At the exit, the hidden state h must be scored by dot product against all V vocabulary columns simultaneously.
A09: when multiplying matrix A of shape (B, T, d_k) by matrix B of shape (B, d_k, T) in batched attention, what is the output shape and how many multiply-add FLOPs does it execute?
The output shape is (B, T, T). Each of the B * T^2 output elements requires a dot product of length d_k (2 * d_k FLOPs), totaling 2 * B * T^2 * d_k FLOPs.
A16: what is the Shannon entropy in bits of a deterministic one-hot distribution [1, 0, 0, 0] versus a uniform distribution over 16 tokens?
A one-hot distribution has H = -1 * log2(1) = 0.00 bits of entropy (zero uncertainty). A uniform distribution over 16 outcomes has H = log2(16) = 4.00 bits.

Short notes

Quick-memorization cheat sheet covering every subtopic on this page and the key facts to remember cold.

All subtopics on this page

  • Q, K, V projections: Linear maps Q = X W_Q, K = X W_K, V = X W_V project each residual row from d_model to d_k in 6 * T * d_model * d_k FLOPs, separating asymmetric search queries, addressable keys, and routable value payloads.
  • Dot-product scoring & 1 / sqrt(d_k) scaling: For unit-variance Q and K, raw scores Q @ K^T have variance d_k and std sqrt(d_k) (7.77 at d_k = 64 in the kata); dividing by sqrt(d_k) restores std ~1.0 (0.97) and keeps softmax entropy at 3.40 bits vs 0.60 bits unscaled.
  • Softmax Jacobian & gradient saturation: Because dp_j / ds_j = p_j(1 - p_j), unscaled logits push p_max -> 1 and collapse the Jacobian factor (0.1786 -> 0.1055 at d_k = 64, down to 0.0024 on T = 6), starving W_Q and W_K of gradients.
  • Causal masking: Upper-triangular entries j > i are set to -infinity (-1e9) before softmax so exp(-inf) = 0 and prefix drift is 0.00e+00; masking with 0.0 leaves exp(0) = 1 and leaks 0.317 average weight per row.
  • Weighted value routing & quadratic cost: Out = A @ V takes a convex combination of past values; computing Q @ K^T and A @ V costs 4 * T^2 * d_k FLOPs and O(T^2) memory, surpassing QKV projection FLOPs once T > 1.5 * d_model.
Important things to remember
  • Master formula: Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k) + M) V with memory hook P-D-S-M-S-V.
  • Row 0 invariant: In causal attention, token t = 0 always has A[0, 0] = 1.000 and entropy 0.00 bits; row i has max entropy log2(i + 1) bits.
  • Leakage test: Perturbing token t must change outputs out[0..t-1] by 0.00e+00. Perplexity ~1.0 in teacher-forced training paired with garbage generation means a broken causal mask.
  • FP16 mask trap: Never hardcode -1e9 into FP16 tensors (min finite value is -65,504); use -float("inf") or torch.finfo(dtype).min.
