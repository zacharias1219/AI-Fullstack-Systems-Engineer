The transformer block

Every modern LLM is a repeating stack of identical decoder blocks wired around one shared residual stream. Why did the field replace Post-LayerNorm and 2-matrix ReLU/GELU MLPs with Pre-RMSNorm and 3-matrix SwiGLU, and what happens to Layer-1 gradients the instant you remove the residual addition?

Before you read

In our 16-layer transformer stack kata (d=32, SwiGLU d_ff=86), Pre-Norm delivers a healthy Layer-1 weight gradient norm ||dL/dW_1|| of 1.516e+00. If you delete the two plus signs (the residual connections x + attn and h + mlp) and keep the exact same weights, what happens to the Layer-1 weight gradient norm?
It collapses by 27 orders of magnitude to 1.087e-27 (and the input gradient ||dL/dx_0|| drops from 1.159e+00 to 2.371e-29), completely killing training at Layer 1. Without the identity term I from residual addition x + F(x), gradients must multiply through 32 sequential projection Jacobians (prod_{l=1}^{16} J_attn J_mlp), vanishing exponentially with depth.
Classic GPT-2 / Vaswani MLPs expand dimension d to d_ff = 4d using two matrices (W_up, W_down). Llama and Mistral use a 3-matrix SwiGLU MLP (W_gate, W_up, W_down) with d_ff = (8/3)d (rounded up to a multiple of 256). Why (8/3)d instead of 4d?
To keep total MLP parameters and FLOPs identical at 8 d^2. A 2-matrix MLP with d_ff = 4d has 2 * d * (4d) = 8 d^2 parameters. A 3-matrix SwiGLU MLP has 3 * d * d_ff parameters; setting 3 * d * d_ff = 8 d^2 gives d_ff = (8/3) d = 2.67 d.
In our kata block (d=32, SwiGLU d_ff=86), what percentage of the block's trainable parameters live inside the SwiGLU MLP versus the 4 attention matrices (W_Q, W_K, W_V, W_O)?
66.8% live in the SwiGLU MLP (8,256 parameters) and only 33.2% live in Attention (4,096 parameters). When you switch from Multi-Head Attention (MHA) to Grouped-Query Attention (GQA, where W_K, W_V are 4x to 8x smaller) and widen the MLP to 3.5d as in Llama-3, the MLP holds nearly 80% of every transformer block's parameters.

The core idea

Think of a decoder-only transformer not as a chain of layers that overwrite a tensor, but as a single shared residual stream highway x_0 -> x_1 -> ... -> x_L of fixed width d_model. Every transformer block has two sublayers that read from the highway through a normalization gate, compute a delta update, and add that update back onto the highway: first Causal Self-Attention (which routes information across token positions t), and second a position-wise SwiGLU Feed-Forward Network / MLP (which transforms each token's feature vector independently across channels d).

Two architectural shifts distinguish modern LLMs (Llama-3, Qwen, Mistral) from the 2017 Vaswani transformer. First, Pre-Norm with RMSNorm moves normalization off the main highway and places it on the branch input (x + Sublayer(RMSNorm(x))), leaving an unobstructed identity path I from the final loss straight back to Layer 0. Second, the 2-matrix ReLU MLP is replaced by a 3-matrix SwiGLU gated bilinear unit ((SiLU(x W_gate) * (x W_up)) W_down), which acts as a input-dependent multiplicative filter and consistently lowers perplexity at matched parameter count 8 d^2.

Memory hook

Remember R-A-R-S on the I-95 Highway: Identity trunk stays completely unblocked; fork 1 runs RMSNorm -> Attention (4d^2 params, mixes tokens) -> Add; fork 2 runs RMSNorm -> SwiGLU (3 * d * (8/3)d = 8d^2 params, mixes channels) -> Add.

How it works

1. The residual stream and why Pre-Norm beat Post-Norm

In the original 2017 Post-Norm block, normalization sat directly on the trunk: x_{l+1} = LayerNorm(x_l + F_l(x_l)). By the chain rule, the gradient reaching Layer 0 must multiply through every layer's normalization Jacobian J_LN. Because variance inside x_l + F_l(x_l) exceeds 1, each Post-Norm Jacobian attenuates the identity path while amplifying early-layer gradient coupling, requiring a delicate learning-rate warmup or training diverges on day one.

In a modern Pre-Norm block, RMSNorm sits inside each residual branch before the weight projection:

h_l     = x_l + Attention(RMSNorm_1(x_l))
x_{l+1} = h_l + SwiGLU(RMSNorm_2(h_l))

Unrolling L layers:  x_L = x_0 + sum_{l=0}^{L-1} [ Attn_l(RMSNorm(x_l)) + SwiGLU_l(RMSNorm(h_l)) ]
Backward Jacobian:   d x_L / d x_0 = I + sum_{l=0}^{L-1} d F_l / d x_0

Because the derivative of x_0 with respect to itself is the identity matrix I, the upstream loss gradient dL / dx_L arrives at every single layer (including Layer 1) attenuated by zero intermediate normalizations or weight matrices. The price of Pre-Norm is that residual stream variance grows linearly with depth (Var(x_L) ~ 1 + 2L * sigma^2, reaching 1.869 at Layer 16 in our depth-scaled kata and 11.813 without 1/sqrt(2L) output projection scaling), which is why a final RMSNorm is mandatory before the LM unembedding head.

2. RMSNorm vs LayerNorm

Standard LayerNorm centers and scales a vector: LN(x) = ((x - mean(x)) / sqrt(var(x) + eps)) * gamma + beta. Zhang & Sennrich (2019) showed that mean-centering adds no accuracy benefit in transformers while wasting memory-bandwidth passes on computing mean(x) and storing bias beta. RMSNorm drops both mean-centering and beta:

RMS(x)     = sqrt( (1/d) * sum_{i=1}^d x_i^2 + eps )
RMSNorm(x) = (x / RMS(x)) * gamma

Each block has two RMSNorm layers (2d trainable scale parameters total per block), cutting normalization kernel latency by ~15-30% while remaining scale-invariant.

Check: Since Pre-Norm allows stream variance Var(x_l) to grow across layers, how do GPT-2 and Llama prevent the residual stream from exploding at 80+ layers?
At initialization, they scale the output projection matrices that write directly into the residual stream (W_O in Attention and W_down in the MLP) by 1 / sqrt(2 * L), where 2L is the total number of residual sublayers. Since 2L independent zero-mean updates add variances linearly, scaling each sublayer's standard deviation by 1 / sqrt(2L) keeps Var(x_L) bounded near O(1) regardless of depth L.

3. SwiGLU vs standard 2-matrix MLP

While Attention routes tokens across time, the MLP processes each token vector z = RMSNorm(h_l) in R^d independently. A classic transformer MLP uses two matrices with intermediate dimension d_ff = 4d: MLP(z) = GELU(z W_1) W_2 (costing 2 * d * 4d = 8 d^2 parameters). Shazeer (2020) introduced SwiGLU (Swish/SiLU Gated Linear Unit), which uses three bias-free matrices W_gate, W_up in R^(d x d_ff) and W_down in R^(d_ff x d):

SiLU(u)   = u * sigmoid(u) = u / (1 + exp(-u))
SwiGLU(z) = ( SiLU(z W_gate) * (z W_up) ) W_down

Here * is elementwise Hadamard multiplication. The bilinear product SiLU(z W_gate) * (z W_up) allows one learned projection to dynamically gate individual feature channels of the other projection, acting like a per-token content lookup table. To keep the parameter count at 8 d^2 across 3 matrices (3 * d * d_ff = 8 d^2), we set d_ff = (8/3) d (or slightly wider in modern GQA models, such as 3.5 d in Llama-3-8B where GQA saves attention parameters).

Check: In the explorer at d=4,096 with GQA 4:1 (8 KV heads / 32 Q heads) and SwiGLU 3.5d (Llama-3 8B config), how many parameters are in one block's Attention vs its SwiGLU MLP?
Attention has W_Q, W_O (2 * 4096^2 = 33.55M) plus 4:1 GQA W_K, W_V (0.5 * 4096^2 = 8.39M) = 41,943,040 parameters (21.2%). The SwiGLU 3.5d MLP has 3 * 4096 * 14336 = 176,160,768 parameters (80.8%), for a total of 218.1M parameters per block.

import math, random

random.seed(7)

def rmsnorm_fwd(x, eps=1e-6):
    d = len(x)
    ms = sum(v * v for v in x) / d
    inv_rms = 1.0 / math.sqrt(ms + eps)
    return [v * inv_rms for v in x], (x, inv_rms)

def rmsnorm_bwd(dy, cache):
    x, inv_rms = cache
    d = len(x)
    dot = sum(dy[i] * x[i] for i in range(d))
    c = (inv_rms ** 2) * dot / d
    return [inv_rms * (dy[i] - x[i] * c) for i in range(d)]

def silu_fwd(z):
    sig = [1.0 / (1.0 + math.exp(-max(-20.0, min(20.0, v)))) for v in z]
    return [z[i] * sig[i] for i in range(len(z))], (z, sig)

def silu_bwd(da, cache):
    z, sig = cache
    return [da[i] * (sig[i] + z[i] * sig[i] * (1.0 - sig[i])) for i in range(len(z))]

def matvec(x, W):
    d_in, d_out = len(W), len(W[0])
    return [sum(x[i] * W[i][j] for i in range(d_in)) for j in range(d_out)]

def matvec_T(dy, W):
    d_in, d_out = len(W), len(W[0])
    return [sum(dy[j] * W[i][j] for j in range(d_out)) for i in range(d_in)]

def rand_mat(r, c, scale):
    return [[random.gauss(0, scale) for _ in range(c)] for _ in range(r)]

def vec_norm(v):
    return math.sqrt(sum(x * x for x in v))

def run_stack(mode, layers, x0):
    x = list(x0)
    caches = []
    for lyr in layers:
        if mode == "prenorm":
            n1, c_n1 = rmsnorm_fwd(x)
            av = matvec(n1, lyr["Wv"])
            attn = matvec(av, lyr["Wo"])
            h = [x[i] + attn[i] for i in range(len(x))]
            n2, c_n2 = rmsnorm_fwd(h)
            g, c_silu = silu_fwd(matvec(n2, lyr["Wg"]))
            u = matvec(n2, lyr["Wu"])
            gu = [g[i] * u[i] for i in range(len(g))]
            mlp = matvec(gu, lyr["Wd"])
            x_next = [h[i] + mlp[i] for i in range(len(h))]
            caches.append((c_n1, n1, c_n2, n2, c_silu, g, u, av, lyr))
        elif mode == "postnorm":
            av = matvec(x, lyr["Wv"])
            attn = matvec(av, lyr["Wo"])
            h, c_n1 = rmsnorm_fwd([x[i] + attn[i] for i in range(len(x))])
            g, c_silu = silu_fwd(matvec(h, lyr["Wg"]))
            u = matvec(h, lyr["Wu"])
            gu = [g[i] * u[i] for i in range(len(g))]
            mlp = matvec(gu, lyr["Wd"])
            x_next, c_n2 = rmsnorm_fwd([h[i] + mlp[i] for i in range(len(h))])
            caches.append((c_n1, x, c_n2, h, c_silu, g, u, av, lyr))
        elif mode == "no_residual":
            n1, c_n1 = rmsnorm_fwd(x, eps=1e-4)
            av = matvec(n1, lyr["Wv"])
            h = matvec(av, lyr["Wo"])
            n2, c_n2 = rmsnorm_fwd(h, eps=1e-4)
            g, c_silu = silu_fwd(matvec(n2, lyr["Wg"]))
            u = matvec(n2, lyr["Wu"])
            gu = [g[i] * u[i] for i in range(len(g))]
            x_next = matvec(gu, lyr["Wd"])
            caches.append((c_n1, n1, c_n2, n2, c_silu, g, u, av, lyr))
        x = x_next

    mean_x = sum(x) / len(x)
    out_var = sum((v - mean_x) ** 2 for v in x) / len(x)
    dx = [1.0 / math.sqrt(len(x))] * len(x)  # unit-norm upstream gradient ||dL/dx_L|| = 1.0
    dw1_norm = 0.0
    for idx in reversed(range(len(layers))):
        c_n1, a1, c_n2, a2, c_silu, g, u, av, lyr = caches[idx]
        if mode == "postnorm":
            dx = rmsnorm_bwd(dx, c_n2)
        d_gu = matvec_T(dx, lyr["Wd"])
        du = [d_gu[i] * g[i] for i in range(len(g))]
        dg = silu_bwd([d_gu[i] * u[i] for i in range(len(u))], c_silu)
        dn2_g = matvec_T(dg, lyr["Wg"])
        dn2_u = matvec_T(du, lyr["Wu"])
        dn2 = [dn2_g[i] + dn2_u[i] for i in range(len(a2))]
        if mode in ("prenorm", "no_residual"):
            dh_mlp = rmsnorm_bwd(dn2, c_n2) if mode == "prenorm" else dn2
            dh = [dx[i] + dh_mlp[i] for i in range(len(dx))] if mode == "prenorm" else dh_mlp
        else:
            dh = rmsnorm_bwd([dx[i] + dn2[i] for i in range(len(dx))], c_n1)
        d_av = matvec_T(dh, lyr["Wo"])
        dn1 = matvec_T(d_av, lyr["Wv"])
        if mode in ("prenorm", "no_residual"):
            dx_attn = rmsnorm_bwd(dn1, c_n1) if mode == "prenorm" else dn1
            dx = [dh[i] + dx_attn[i] for i in range(len(dh))] if mode == "prenorm" else dx_attn
        else:
            dx = [dh[i] + dn1[i] for i in range(len(dh))]
        if idx == 0:
            dw1_norm = vec_norm(a1) * vec_norm(d_av) + vec_norm(a2) * vec_norm(du)
    return out_var, vec_norm(dx), dw1_norm

L, d, d_ff = 16, 32, 86  # SwiGLU d_ff = ceil((8/3)*32) aligned = 86
s_in = 0.14
s_res = 0.14 / math.sqrt(2 * L)
layers = [{"Wv": rand_mat(d, d, s_in), "Wo": rand_mat(d, d, s_res),
           "Wg": rand_mat(d, d_ff, s_in), "Wu": rand_mat(d, d_ff, s_in),
           "Wd": rand_mat(d_ff, d, s_res)} for _ in range(L)]
x0 = [random.gauss(0, 1) for _ in range(d)]

print(f"=== 16-Layer Transformer Block Stack (d={d}, SwiGLU d_ff={d_ff}) ===")
p_attn, p_mlp = 4 * d * d, 3 * d * d_ff
print(f"Params per block: Attention={p_attn:,} ({100*p_attn/(p_attn+p_mlp):.1f}%) | SwiGLU MLP={p_mlp:,} ({100*p_mlp/(p_attn+p_mlp):.1f}%)")
for mode in ["prenorm", "postnorm", "no_residual"]:
    var_L, dx0_norm, dw1_norm = run_stack(mode, layers, x0)
    print(f"Mode={mode:11s} | Layer-16 Act Var={var_L:6.3f} | ||dL/dx_0||={dx0_norm:.3e} | Layer-1 ||dL/dW_1||={dw1_norm:.3e}")

Traps

Each one sounds right. Say what is wrong with it before you open it.

"SwiGLU uses d_ff = (8/3)d because a narrow bottleneck acts as a regularizer that prevents overfitting compared to 4d."
False. The (8/3)d width has nothing to do with bottleneck regularization; it is pure parameter-and-FLOP accounting. A standard 2-matrix MLP (W_1, W_2) with width 4d has 2 * d * 4d = 8 d^2 parameters. Because SwiGLU requires three matrices (W_gate, W_up, W_down), keeping the parameter budget at 8 d^2 requires 3 * d * d_ff = 8 d^2, which solves to d_ff = (8/3)d.
"Pre-Norm and Post-Norm have the exact same gradient flow because both include residual connections x + F(x)."
False. In Post-Norm (x_{l+1} = Norm(x_l + F(x_l))), the normalization wraps the entire sum on the trunk, so the backward pass multiplies the upstream gradient by the normalization Jacobian J_Norm at every single sublayer (2L times). Since Var(x + F(x)) > 1, those 2L Jacobians attenuate the identity path relative to local branch gradients. Only Pre-Norm (x_{l+1} = x_l + F(Norm(x_l))) leaves the trunk identity term I completely outside all normalization Jacobians.

Answer aloud, then open. Grade yourself honestly.

Write the unrolled forward equation for Layer L in a Pre-Norm transformer and use it to derive d x_L / d x_0.
By induction on x_{l+1} = x_l + F_l(RMSNorm(x_l)), the final state is x_L = x_0 + sum_{l=0}^{L-1} F_l(RMSNorm(x_l)). Differentiating with respect to x_0 gives d x_L / d x_0 = I + sum_{l=0}^{L-1} d F_l(RMSNorm(x_l)) / d x_0. The additive identity matrix I guarantees that gradients flow directly from Layer L to Layer 0 without vanishing.
Follow-upWhat is the product form of d x_L / d x_0 when the residual addition x_l + ... is removed? It becomes a pure product of 2L sublayer Jacobians prod_{l=0}^{L-1} J_{MLP,l} J_{Attn,l}, which decays exponentially as sigma^(2L) (collapsing to 2.371e-29 at L=16 in our kata).
Why do modern LLMs use RMSNorm instead of standard LayerNorm, and how many trainable parameters does RMSNorm add per block?
RMSNorm omits mean subtraction (x - mu) and the additive bias vector beta, normalizing purely by the root-mean-square sqrt((1/d) sum x_i^2 + eps) and scaling by gamma in R^d. Because a block has two RMSNorm layers (pre-attention and pre-MLP), it adds only 2d trainable parameters per block while cutting memory-bandwidth reduction passes in half.
Derive the total parameter count of one transformer block with Multi-Head Attention and a SwiGLU MLP of width d_ff = (8/3)d (ignoring RMSNorm's 2d).
Multi-Head Attention has 4 square projection matrices W_Q, W_K, W_V, W_O in R^(d x d) = 4 d^2 parameters. SwiGLU has 3 matrices W_gate, W_up in R^(d x (8/3)d) and W_down in R^((8/3)d x d) = 3 * d * (8/3)d = 8 d^2 parameters. Total per block = 4 d^2 + 8 d^2 = 12 d^2 parameters (33.3% Attention, 66.7% MLP).
Follow-upHow do hardware engineers round d_ff = (8/3)d in practice? They round up to the nearest multiple of 256 (or 128) so Tensor Core tile dimensions divide evenly without padding overhead (for example, at d=4096, (8/3)*4096 = 10,922.67 rounds up to 11,008 = 43 * 256 in Llama-2 7B).
Why does Pre-Norm require a final RMSNorm layer right before the LM unembedding head W_head, whereas Post-Norm did not?
In Pre-Norm, each sublayer adds an unnormalized vector directly onto the residual trunk, so the stream variance Var(x_l) grows monotonically with depth l. Without a final RMSNorm after Layer L, the logits x_L W_head^T would have huge scale and drift during training, causing softmax saturation and loss spikes.
Explain how W_gate and W_up in a SwiGLU layer are fused during inference and why this matters for decode latency.
At batch=1 autoregressive decode, MLP execution is strictly memory-bandwidth bound. Because z W_gate and z W_up multiply the exact same normalized input vector z = RMSNorm(h_l), concatenating W_gate and W_up into one (d, 2 * d_ff) matrix lets the GPU read z once, run a single larger GEMV, and apply a fused SiLU(first_half) * second_half kernel in SRAM before multiplying by W_down.
Contrast the computational roles of the Attention sublayer and the SwiGLU MLP sublayer inside a transformer block.
Attention is the token-mixing operator: it computes dynamic routing weights across sequence positions 1..t so token t can gather context from earlier tokens, operating in low-rank head subspaces d_head. The SwiGLU MLP is the channel-mixing operator: it applies zero cross-token interaction, expanding each token's vector independently into a wide d_ff gated feature space where factual associations and nonlinear transformations are stored.

Mixed review

Three questions from earlier topics. Nobody tells you the topic in an interview.

D06: Why does RoPE apply 2D rotations to Queries and Keys at every attention layer, and why does it never rotate Values?
Rotating Q by m * theta_i and K by n * theta_i makes their dot product q_m^T R_m^T R_n k_n = q_m^T R_{n-m} k_n depend strictly on relative distance n - m at every layer. Values hold semantic content that is linearly summed after softmax; rotating V would corrupt content vectors with an uncancelled position phase.
D05: What is the difference between Multi-Query Attention (MQA) and Grouped-Query Attention (GQA), and why did Llama-2 70B and Llama-3 8B choose GQA?
MQA shares a single Key and Value head (G=1) across all H_q query heads, which maximally shrinks the KV cache by H_q times but degrades quality and training stability. GQA partitions query heads into G=8 groups (each group sharing 1 KV head), capturing nearly all of MQA's KV-cache bandwidth savings (4x to 8x reduction) with zero quality loss compared to MHA.
D02: When embedding table W_E in R^(V x d) is tied to the output LM head W_head, how many parameters are saved in a model with V = 128,256 and d = 4,096?
Weight tying saves one full V * d = 128,256 * 4,096 = 525,336,576 (~525M) parameter matrix, though large models (like Llama-3 70B) often untie them when 525M is a tiny fraction of total weights so input and output spaces can specialize independently.

Short notes

Quick-memorization cheat sheet covering every subtopic on this page and the key facts to remember cold.

All subtopics on this page

  • Residual stream & Pre-Norm highway: Each block updates a continuous trunk via h_l = x_l + Attn(RMSNorm(x_l)) and x_{l+1} = h_l + SwiGLU(RMSNorm(h_l)), giving an unobstructed backward identity highway d x_L / d x_0 = I + sum(dF_l / dx_0).
  • Why training dies without residuals: Removing the + nodes forces gradients to multiply through 2L weight Jacobians; in our 16-layer kata, Layer-1 weight gradient norm ||dL/dW_1|| collapses from 1.516e+00 to 1.087e-27.
  • RMSNorm vs LayerNorm: RMSNorm drops mean subtraction and bias beta, computing (x / sqrt(mean(x^2) + eps)) * gamma with only 2d parameters per block.
  • SwiGLU 3-matrix MLP: Computes (SiLU(z W_gate) * (z W_up)) W_down; setting d_ff = (8/3)d matches the 8 d^2 parameter count of a 2-matrix 4d MLP (66.7% of an MHA block, or ~80.8% of a Llama-3 GQA block).
Important things to remember
  • Parameter count per MHA + SwiGLU block: Attention = 4 d^2 (33.3%), SwiGLU MLP = 3 * d * (8/3)d = 8 d^2 (66.7%), Total = 12 d^2 + 2d.
  • Depth-scaled initialization: Because Pre-Norm adds unnormalized updates to the residual stream, initialize output projections W_O and W_down with standard deviation scaled by 1 / sqrt(2 * L) and apply a final RMSNorm before the LM head.
  • Inference kernel fusion: Concatenate W_gate and W_up into a single (d, 2 * d_ff) matrix and fuse SiLU(gate) * up in SRAM to save a global memory read during batch=1 decode.
  • Division of labor: Attention mixes information across token positions T; the SwiGLU MLP mixes and gates features across channel dimensions d per token independently.
